# Real-model test: the history without a language model

Workload: requests to a virtual assistant, routed to 10 departments (CLINC150 domains). Same split as REPORT_departments.md: thresholds on the calibration half (2250 requests), every figure on the test half (2250 requests), 95% bootstrap intervals.

The classifier is TF-IDF over words and word pairs with logistic regression, trained on labelled past requests. The language models answer with no examples, as in the main report.

This file is generated by `python -m realtest.baselines --task departments`.

Accuracy is on the test half. Compute for the classifier is a batched prediction over all requests on a different machine; for the models it is the mean over all requests, one at a time, on the office PC of the main run. Only the order of magnitude compares.

## With few labelled examples

For each size, labelled examples are drawn at random from the history (5 draws, mean shown). The hybrid sends to qwen2.5:7b the requests on which the classifier is not confident enough; the threshold on its top class probability (uncalibrated, grid of 0.02) is the one with the highest accuracy on the calibration half; cost is not part of the choice. Its compute, against qwen2.5:7b alone, is roughly the share it sends. The difference is a paired bootstrap interval on the test half, with each request's outcome averaged over the draws.

## Limits

- One task with 10 broad categories and many labelled examples: an easy case for a classifier.
- The classifier is not tuned beyond sublinear TF and C = 10; the language models are not tuned either (one zero-shot prompt, default quantization).
- New categories, or categories with no labelled history, are not tested here: that is where a language model that reads the category names should matter most.

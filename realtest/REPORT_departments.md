# Real-model test: report

Workload: requests to a virtual assistant, routed to 10 departments (CLINC150 domains). 4500 requests. Calibration half 2250, test half 2250. Every figure below is measured on the test half; intervals are 95% bootstrap intervals.

The models answer with the name of the department. They are shown the list and no example requests.

This file is generated by `python -m realtest.analyze --task departments --shots 0` from the stored outputs in `realtest/outputs/departments/names-0shot/`.

Cost: 0.34 ms per request, 0.0039 of the smallest model.

Each design that uses the stage picks its similarity threshold on the calibration half, together with the confidence threshold, so that the whole cascade stays within the tolerance. The simulation assumed a stage 99.5% accurate, with a coverage chosen by hand.

## The 5x rule on these models

For each small, middle, large triple: what a third stage adds to the two-stage cascade, in points of saving against the large model of the triple. The step is the average cost ratio between neighbours.

| qwen2.5:0.5b, qwen2.5:3b, qwen2.5:7b | 2.6x | -15% | -28.8 (-30.4 to -27.1) | +89.1 (+87.3 to +90.8) |
| qwen2.5:1.5b, qwen2.5:3b, qwen2.5:7b | 1.9x | -24% | -35.3 (-36.7 to -33.9) | +112.9 (+111.7 to +113.9) |

Under 5x the rule predicts that a middle model does not pay and that a rule stage does. Of 4 triples under 5x:

- the middle model clearly gains in 1 and clearly loses in 3;
- the lookup stage clearly gains in 4 and clearly loses in 0.

Clearly means that the whole 95% interval is on one side of zero.

No triple reaches 5x: this run says nothing about the upper branch of the rule.

## Limits of this run

- One task, one model family, one machine. It is a first measurement, not a validation.
- The models classify without example requests; the lookup stage uses all 15,000 labelled past requests.
- Costs are measured with the instructions cached between requests, as a server would run it.
- Thresholds are chosen on the calibration half. On the test half a design can end up more than half a point below the large model: check the accuracy column before comparing savings.
- With 2250 test requests, differences of a few points are within noise: read the intervals.
